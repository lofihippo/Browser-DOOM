Controls

  • W/A/S/D or Arrows — move / strafe
  • Mouse — turn
  • Mouse click / Ctrl — fire
  • Space — open / use
  • Shift — run
  • Alt — strafe
  • F1 — game options · F2 — save · F3 — load
  • Esc — game menu / release mouse
  • Click canvas to capture the mouse (pointer lock) for camera turning

This build ships the doomgeneric engine (GPL-2.0). Doom's original control model turns horizontally; there is no vertical mouse-look.

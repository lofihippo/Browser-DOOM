Controls

  • Arrow keys — ↑/↓ move, ←/→ turn
  • Alt + ←/→ — strafe (or , / .)
  • Ctrl — fire
  • Space — open / use
  • Shift — run
  • 1–7 — switch weapon
  • Tab — automap
  • F2 — save · F3 — load (current session only)
  • Esc — game menu

This build ships the doomgeneric engine (GPL-2.0), whose input API is keyboard-only — the mouse does nothing in-game.
